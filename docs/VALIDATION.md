新增核心测试覆盖快捷键前不触发 API、编辑/焦点/暂停/模式切换使授权失效、只允许真实选区、旧主题迁移、系统主题解析、半透明参数持久化，以及输入区域和光标避让。

Windows UiSmoke 检查实际设置窗口的主题切换、搜索、模型编辑与设置保存；检查短/长译文尺寸、背景透明度、选区隐藏替换按钮，并生成 PNG。独立 WPF 输入进程通过真实 UIA 验证快捷键输入、编辑后失效、只读选区、清除选区和密码跳过。不调用付费 API。

悬浮窗、图标和输入读取均保留生产代码路径；UIA 提供程序无法读取时跳过，不使用模拟按键或剪贴板读取后备。全屏编辑区域可能无法完全避让，优先保护光标附近，亦可选择快捷键模式。

程序和压缩包校验值以安装包内“文件校验.txt”及版本附件 SHA256SUMS.txt 为准。
