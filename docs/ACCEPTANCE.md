# Windows 手工验收 A–H

以下是可执行清单，**尚未在本次 Linux 云环境执行**。需要 Windows 10/11 普通桌面会话、所选服务的可用 API 账户与网络。建议先用 InputLab，随后逐一测试自己的应用；不要直接用敏感会话验收。

## 准备

```powershell
dotnet restore TypeLingo.sln --locked-mode
dotnet build TypeLingo.sln -c Release --no-restore
dotnet run --project src/TypeLingo.App -c Release --no-build
# 在第二个终端：
dotnet run --project tools/TypeLingo.InputLab -c Release --no-build
```

在设置中保存 Key、选择服务商、查询可用模型并选择或填写模型 ID。在“隐私与应用”授权；如需隔离验收范围，关闭“监控所有应用”，仅允许 `TypeLingo.InputLab`。保持默认防抖 500 ms、间隔 700 ms，磁盘缓存关闭，目标 `ja`。测试初始清缓存，记录「隐私」页中的会话请求数；观察完统计后回到输入框（设置窗口获得焦点会隐藏预览）。

## H 的细分步骤

1. **断网 / Key 错误**：断网后输入新文本，或保存错误 Key。应显示简短错误，不弹出连续错误对话框。恢复网络/正确 Key 后修改文本重新触发。认证错误不重试。
2. **429 / 5xx / 超时**：自动测试用 HTTP handler 精确覆盖重试及超时分类；实际服务若触发 429，应有限重试后提示受限。不要故意大量发送请求制造真实限流。将超时设为 1 秒可观察慢网络失败；失败不得写原文。
3. **不支持 UIA**：聚焦不可访问控件，预览隐藏。TextPattern-only 可编辑框允许预览，替换按钮不可用。不得为了兼容而启用提权、注入或键盘钩子。
4. **IME**：原生 A 使用中文拼音/日文假名，停留在候选阶段超过 500 ms，再提交。IMM 可见的组合阶段不得翻译或写入。对 TSF 状态未知控件，预览可能暂时反映未提交文本，中/日/韩布局下替换必须禁用；可主动复制。提交后切至英文布局，再检查可写状态是否恢复。
5. **多屏/DPI**：在 100% 与 150%/200% 显示器间拖动 InputLab，覆盖负坐标屏幕；移动、缩放、滚动、最小化、切换焦点。预览应跟随输入框且不抢焦点、避开任务栏；在四边空间不足时落在屏幕工作区内。尺寸极小的工作区需记录裁切情况。
6. **暂停/授权**：输入过程中用托盘暂停，预览隐藏、后续输入不增加请求。在指定应用模式下，空允许列表不读取；在所有应用模式下，普通可访问进程无需允许列表。两种模式均必须遵守排除、敏感控件及取消授权。重新授权并保存后恢复。
7. **快捷键冲突**：配置重复组合或被其他软件占用的组合，保存后明确提示冲突；不悄悄使用其他组合。修正后再保存。
8. **磁盘缓存**：主动启用磁盘缓存，翻译一次，退出重启后重输。应本地命中；关闭磁盘后清全部缓存，重启再开启，旧条目应不可命中。不要把私人原文拿来做缓存验证。
9. **重启与退出**：关闭设置仍留在托盘，退出托盘终止程序。未确认的票据不会跨重启恢复。第二个实例不重复注册监视。新任务/新进程需要重新启动应用，不能依赖云快照保留运行中的进程。

记录应用版本、Windows 版本、进程名、控件类型、输入法、屏幕 DPI 及通过/失败情况，**不要记录私人原文、API Key 或密码**。本清单全部通过后才能声称对应 Windows 组合已完成桌面验收。

## 本轮新增验收：多语言、模型与中文安装

以下仍需真实 Windows 会话验收，本次 Linux 未执行：

1. 切换简体中文、英语、日语，检查全部标签、托盘、悬浮窗与确认提示随语言变化；保存重启后保持所选语言，翻译方向不随之改变。
2. 选择中译英、英译中、中译日等九种预设，检查源/目标下拉框正确联动；手动改语言后，预设匹配或显示自定义。
3. 逐一切换五家服务，打开官方平台，核实浏览器地址与文档一致。测试按钮只会查询模型或发送固定 Hello，不发送当前监视输入。
4. 为两家服务分别保存不同密钥，切换后不能错误复用；改变 API 地址后必须重新填写对应密钥。模型列表返回前切换服务，不得覆盖新服务的模型框。
5. 使用账户真实模型做固定短句测试，再用输入框验收。模型无权限或不存在时显示错误，不静默更换模型。
6. 解压中文包，运行安装向导，检查 SHA-256 校验、当前用户安装目录、桌面/开始菜单中文快捷方式；更新前正常退出；卸载不能删除用户配置或其他应用的快捷方式。

## v0.2.0 所有应用与 Windows 11 设置风格

1. 授权并开启“监控所有应用”，不填写允许列表，分别在记事本与浏览器的可访问输入框验证预览。
2. 把其中一个进程加入排除列表并保存，即使所有应用开关开启也不得读取、请求或写入。
3. 关闭所有应用模式，仅允许 notepad，浏览器不再监控；空列表不监控任何应用。
4. 使用左侧导航切换所有页面。搜索“密钥”“字体”“缓存”，应定位对应页；不存在的词显示空结果，清空搜索后恢复导航。
5. 检查 900×760 和较小的 820×560 窗口、100%/150%/200% DPI，卡片和输入框无重叠、底部保存按钮可见；长说明自动换行，内容可滚动。
6. 切换中英日界面与深浅主题，卡片、输入框、下拉菜单、悬浮窗与系统标题栏保持可读；手动模型输入和预设联动继续有效。
7. Windows 自动验证工具可执行：dotnet run --project tools/TypeLingo.UiSmoke -c Release -- artifacts/ui-smoke。真实 UIA、IME 和第三方输入框兼容性仍按上面的手工清单验收。

## v0.3.0 简洁界面与紧凑悬浮窗

1. 对照实际 PNG 检查白底分隔行、线性图标、黑色开关、三种主题卡片及小窗口保存按钮。切换系统深浅设置时，跟随系统主题应同步变化。
2. 在常规设置切换三种出现方式。输入模式停顿后显示；快捷键模式在 Ctrl+Alt+T 前不读取文本或请求 API，编辑或切换焦点后须重新触发。
3. 选区模式只翻译实际选中文字，清空选区后隐藏；只读文档公开选区时可以预览、复制、收藏，不显示替换按钮。可编辑选区在提供可靠 ValuePattern 和范围时支持确认替换。密码或排除进程始终跳过。
4. 短译文自动收窄，长译文限制高度且可滚动；复制/替换/关闭图标有工具提示，确认替换仍需要第二次明确操作。
5. 默认背景半透明、正文清晰；悬停恢复实色并暂停隐藏。验证默认 8 秒自动隐藏、0 秒保持显示、手动关闭，以及输入框/光标/选区避让与多屏 DPI。
6. 使用错误密钥验证简短错误气泡，悬停可见具体原因，不覆盖输入正文。

UiSmoke 提供受控 Windows WPF 与跨进程 UIA 自动记录；此清单仍用于补充第三方应用和真实输入法的手工验收。


## I. 当前行、Loading 与本地复习（本轮待 Windows 实机验收）

1. 在多行输入中选中中间一段，预览后点击译文并确认：只有选区被替换，前后文字和其他行不变。选择重复词语的第二处，确认不会替换第一处。
2. 清除选区，把光标放在第二行；预览与确认只处理第二行，保留 CRLF 和其他行。确认前在其他行编辑，旧确认应拒绝写入。
3. 只读选区可复制与收藏，不出现替换按钮；无法核对 UIA 范围的控件不执行写入。密码、排除项和中日 IME 继续验证。
4. 常规设置选择「翻译完成后显示」并保存，重启仍保持；选择「翻译中显示 Loading」后，等待与请求阶段可见进度，成功、失败、焦点变化和暂停时进度结束。
5. 点击星标，在收藏页搜索原文或译文；重复收藏不增加条目。退出重启后条目仍在，清缓存不会删除收藏。删除需确认。
6. 开始到期复习时先隐藏译文，揭示后才能自评；记住后推迟到期，再练一次后 10 分钟到期。重启后保留进度，整个复习过程不发 API 请求。
7. 主页位于导航首位并默认显示。验证 EXE、托盘、窗口与主页使用同一份品牌资源；确认宣传图仅作为交互示意。


## J. 设置布局与新版 Teams

1. 在主页、常规、AI、外观、快捷键、缓存、隐私、收藏之间用鼠标和键盘切换，导航行与文字位置不跳动；较短与较长页面的视口宽度不变。
2. 空搜索框聚焦时占位文字隐藏，光标从左侧开始；输入后光标跟随文字；清空并失焦后恢复提示。
3. 在常规页切换两种翻译窗口显示时机，保存、重启及切换界面语言后保持选择。结果模式等待期间不弹窗，Loading 模式显示进度。
4. 新版 Teams 中开启输入后自动出现，在已授权输入框键入普通测试短句；应显示译文。选用允许列表时只需授权 `ms-teams` 宿主，不需要全局允许渲染进程。
5. 切换到未授权宿主、排除宿主或渲染进程、密码框和暂停状态时均不读取或翻译；TextPattern 富文本不支持安全写入时仅复制与收藏。
6. 本地 WebView2 回归验证不代表已登录并测试用户所在组织的 Teams 版本；实际 Teams 验收请记录版本、语言、触发模式和是否显示预览。


## 默认划词与阅读选区

1. 全新配置默认划词；无选区时键入不产生请求。旧输入模式首次升级切换，随后保存输入模式并重启仍保留。
2. 在网页、文档、聊天记录等阅读区域拖选文字，松开后只翻译所选内容；拖选中无中间请求。阅读区没有键盘焦点也可捕获。
3. 移动到悬浮窗复制和收藏仍可操作；取消选区或切换前台应用后隐藏，不能退回全文。
4. 只读区域没有替换按钮，可编辑选区继续验证精确替换。确认密码、排除项、指定应用和前台窗口归属约束。
5. 不公开 UIA 文本选区的应用、图片或扫描 PDF 记录为不支持，不使用剪贴板后备。
