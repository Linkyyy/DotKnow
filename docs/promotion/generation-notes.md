# 素材来源

宣传图使用图像生成工具制作，参考仓库原有黑白 A／文对话气泡 Logo。图中的编辑器、悬浮窗和卡片为交互示意，并非 Windows 截屏。生成后人工检查了主要中文标题、示例译文、功能说明和联网边界。

主图内容：TypeLingo · 伴译；让表达跨越语言；输入、翻译、收藏、复习，一气呵成；选区／当前行翻译；确认后替换；本地收藏与复习。

方图内容：把好表达，留在本地；本机加密保存；无需重复调用 API；复习可离线，翻译需连接所选 AI 服务。

独立的新 Logo 文件未在当前会话提供。当前程序和宣传图沿用仓库 SVG，并统一设置页 PNG、EXE 与托盘 ICO。拿到新素材后，替换源 SVG 并运行 `scripts/render-brand.sh`，同时重新生成含品牌图标的宣传图。
