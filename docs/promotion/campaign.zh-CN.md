# 点解 DotKnow · 产品定位与宣传方案

## 新定位

品类：划选即问的桌面 AI 助手。
名字：点解 · DotKnow，由 TypeLingo · 伴译升级而来。
主宣传语：哪里不会，点哪里。
解释句：像点读机一样，把屏幕上的疑问选出来。
核心动作：划选 → 选任务或输入问题 → 获得回答 → 复制、收藏与复习。

「点解」是粤语里的“为什么”。它把好奇、提问与理解串在一起：哪里有疑问，就划选哪里。沿用用户已选定的 C 图形，含义扩展为内容与回答之间的连接。视觉保持奶油白、深林绿、青柠色，桌面可切换五套配色，并支持浅色、深色与跟随系统。

## 三个传播重点

1. 把疑问留在原地：读网页、文档、邮件和代码时，划选一小段就能提问。
2. 你决定怎么答：7 套内置预设，也能保存自己的提示词，临时问题直接输入。
3. 翻译依然好用：中英日互译，保留离线词库、自动积累、本地收藏和复习。

面向学生与自学者：陌生概念 → 通俗解释 → 收藏与复习。
面向职场阅读者：长段落 → 提炼重点；外文 → 翻译。
面向开发者：代码片段 → 代码解读；强调阅读辅助，不宣传自动执行。

## 官网结构

首屏“哪里不会，点哪里”，固定示例展示百科、翻译和自由提问；其次展示划选、提示词与积累，再列 7 套预设。保留独立离线翻译区域，清晰说明百科需要在线模型。FAQ 说明支持范围、旧版升级、隐私和 AI 的边界。首屏和页底均有 Windows 下载入口。

## 发布与短内容

发布标题：为什么？选中就问。点解 DotKnow：哪里不会，点哪里。
首发图：主宣传语＋百科交互示意，明确标注固定示例。
第二张：任务与提示词真实界面，突出百科、翻译与自定义。
第三张：离线翻译真实界面，说明词库只作用于翻译。
15 秒演示：0–3 秒划选陌生概念；3–7 秒选择百科；7–11 秒补充问题并展示回答；11–15 秒复制或收藏，展示下载入口。

首周侧重场景演示和收集 UIA 应用兼容反馈；后续发布学习教练、英文阅读和批判性阅读等可复制模板。使用实际界面录屏；固定测试数据与交互示意必须明确标注。

## 文案约束

不宣传实时联网搜索、权威核验、支持所有软件、图片识别、离线大模型或免费无限在线使用。离线数字采用 6426 组与 32159 条方向记录，不以展开数量宣传一万组。用户自备 API Key，服务商可能收费。AI 回答可能出错。

下载包和官网使用 DotKnow 名称。仓库与程序集统一使用 DotKnow。本地数据目录、加密上下文和单实例标识继续兼容 TypeLingo，以保留旧配置、密钥、题库和收藏。
