# 宣传标题

让表达跨越语言。

# 一句话介绍

TypeLingo · 伴译，让输入、翻译、收藏、复习连成一个自然的流程。

# 项目短介绍

在 Windows 上写邮件、聊天或整理文档时，TypeLingo 会在获得授权后翻译选中文字或光标所在行，并在旁边显示译文。点击译文即可查看替换确认，确认后只更新对应范围。遇到值得留住的表达，点击星标收藏，稍后用本地卡片复习。

# 功能卡片文案

- **跟随输入的翻译**：自动、快捷键或选区触发，选择适合自己的方式。
- **替换范围更准确**：有选区就替换选区，否则替换当前行，保留前后文字和其他行。
- **等待有反馈**：Loading 进度可在设置中开启或关闭。
- **好表达留在本地**：主动收藏原文与译文，用当前 Windows 用户 DPAPI 加密保存。
- **收藏之后再复习**：先看原文，再揭示译文，根据记忆情况安排下一次复习。
- **主页更顺手**：主页放在导航首位，默认打开，快速查看当前状态。

# 社交平台文案

每次翻译，都可能遇到一句值得记住的表达。

TypeLingo · 伴译，支持选区／当前行翻译、确认替换、Loading 显示，以及本地收藏与卡片复习。翻译时连接自己选择的 AI 服务，复习时直接使用本机保存的内容，无需再次调用 API。

适用于 Windows 10 / 11。当前 v0.4.0-preview.2 为开发候选版；实际桌面效果与兼容性以 Windows 验收为准。

# 发布说明草稿

本轮启用全新 C 双向对话品牌图形，统一程序、窗口、首页与托盘图标，并更新宣传图。托盘按系统任务栏主题切换黑白单色标。支持主页置顶、Loading 开关、本地加密收藏和到期复习。点击译文或替换图标进入确认，写入前重新核对目标、原文、范围和输入法状态，拒绝过时内容。

本地收藏由用户主动保存，与可清除的翻译缓存分开。复习不调用 API；翻译需要所选服务的网络与密钥，可能产生 API 费用。密码框、敏感控件、排除项及暂停设置继续生效；无法验证安全写入的控件提供复制与收藏。
