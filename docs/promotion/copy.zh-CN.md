## 一句话介绍

点知是一款 Windows 划选即问的桌面 AI 助手：哪里不会，点哪里，查百科、做翻译，也能用自己的提示词问 AI。

## 约 100 字介绍

像点读机一样，把疑问选出来。点知 DotKnow 支持百科、翻译、通俗解释、摘要、写作润色、代码解读和自由提问，还能保存自己的提示词。翻译保留中英日离线词库，有用的回答可收藏并在本地复习。适用于 Windows 10 / 11 x64，在线任务使用你自己的 API。

## 必要说明

需要应用公开文本选区；不支持 OCR。百科等 AI 任务需要在线模型和自备 API Key，可能产生费用；没有实时联网检索或来源核验。离线是翻译词库精确匹配，AI 回答可能有误。固定示例和真实截图在各素材说明中区分。

## v0.5.0-preview.2 补充文案

纯白主题，干净一点；百科回答，简单一点。选中疑问即可查，想深入时再展开追问。

新增微信可复制文字的划选兼容路径。关闭结果后，同一段文字保持安静，重新划选再出现。微信版本、控件和权限可能影响兼容性，不提供图片 OCR。
