# 来源与许可证说明（REFERENCES）

## 本包内容性质
`vocabulary.jsonl` 与 `entries.jsonl` 中的词条为本词库编写过程中逐条人工编写、
人工核对的三语对应表达；本包**未原样复制**任何第三方词典的词条文本。

## 编写过程中仅作对照参考、未随包分发的外部资料
以下资料曾在编写时用于核对常用表达，但其数据文件**没有**进入本包，
因此不构成再分发；列出仅为透明说明：

1. **CC-CEDICT**（简体/繁体中文—英文社区词典，MDBG 发布）
   - 许可证：Creative Commons Attribution-ShareAlike 4.0 International (CC-BY-SA 4.0)
   - 来源：https://www.mdbg.net/chinese/dictionary?page=cc-cedict
   - 用途：仅用于核对中文常用词的英文对应，未收录其词条原文。

2. **OpenJLPT**（JLPT N5–N1 日语—英语词汇表，evanclan 维护，基于 JMdict 与
   Jonathan Waller 社区级别表交叉核对）
   - 许可证：Creative Commons Attribution-ShareAlike 4.0 International (CC-BY-SA 4.0)
   - 来源：https://github.com/evanclan/OpenJLPT
   - 用途：仅用于核对日语常用词的英文对应，未收录其词条原文。

## 本包汇编作品许可证
本词库的汇编（挑选、编排、六向展开、冲突隔离）采用
**Creative Commons Attribution 4.0 International (CC-BY-4.0)**。
若后续改为直接收录 CC-BY-SA 资料原文，必须相应改用 CC-BY-SA 4.0 并按
ShareAlike 要求开放衍生内容，届时以本文件更新为准。

## 第三方运行组件
本包为纯 JSONL 数据，不附带任何运行库、模型或可执行程序，
因此不涉及 ONNX Runtime、.NET 或其他引擎的许可证分发。
