# v0.5.0-preview.2 · 划选与界面优化

新增纯白主题、按文字收紧的选择控件与简洁百科结果。关闭同一选区的窗口后不会因焦点恢复而重复触发，重新划选或使用快捷键可以再查。

微信缺少可访问文本选区时，使用临时复制路径获取用户选中的文字，随后恢复原剪贴板；该路径不具备替换权限，遵守暂停、隐私授权、进程排除和长度限制，可在常规设置关闭。仅支持微信本身可复制的文字，不包含图片 OCR；软件与微信需位于可交互的同一 Windows 桌面和权限环境。

项目和程序程序集改名为 DotKnow，本地配置目录、DPAPI 加密上下文和单实例标识保留兼容。

验收覆盖 Linux 核心测试及 Windows WPF、辅助功能接口、微信式自绘控件和剪贴板恢复。具体 Windows 结果以对应源码提交的 CI 报告为准。

# v0.5.0-preview.1 · 点知 DotKnow

产品从 TypeLingo 伴译升级为“划选即问的桌面 AI 助手”。主宣传语：**哪里不会，点哪里。** 翻译保留为独立重要模式。

- 新用户默认划选后出现任务与提问面板，点击查询才发送；也可立即执行默认预设。
- 内置百科、翻译、通俗解释、提炼重点、写作润色、代码解读、自由提问七套提示词；支持最多 20 套自定义模板。
- 面板可输入补充问题，Ctrl+Enter 查询；保留失焦前的外部选区，支持长回答滚动、复制和收藏。
- 纯翻译继续使用离线词库、在线回退、缓存自动入库和安全确认替换。其他任务及翻译的补充提问与词库隔离，缓存按实际指令与问题区分。
- 收藏记录任务和问题；旧版配置、API 密钥、词库、缓存与收藏沿用原目录。旧用户保留即时翻译模式。
- 界面、托盘名称、官网、Windows 分发文件、中文安装向导和宣传资料更新为点知。程序为 DotKnow.exe，C 图标及四套主题保留。

百科等任务使用用户选择的在线模型和 API Key，可能产生服务商费用；当前没有实时联网搜索或来源核验。离线能力仍为翻译词库精确查询。

使用方法见 [划选助手](ASSISTANT.md)，可复制模板见 [提示词示例](PROMPT_PRESETS.md)，实测结果见 [验证记录](VALIDATION.md)。

# v0.4.0-preview.5 — 离线题库优先

# TypeLingo（伴译）v0.3.0

## 本次更新

- 按新的参考图重做白底设置：窄侧栏、分隔行、浅灰输入框、黑色开关，提供浅色/深色/跟随系统三张主题卡片。
- 全部导航及悬浮窗图标改为统一线性矢量资源，替换 EXE、窗口和托盘品牌图标。
- 悬浮窗精简为译文与复制、替换、关闭图标，短译文自动收窄，长译文滚动，背景半透明且文字保持清晰。
- 新增三种出现方式：输入后自动出现、快捷键触发、选中文字后出现。默认快捷键 Ctrl+Alt+T，可在设置修改。
- 快捷键触发前不读取文本；编辑、焦点或配置变化后需要重新触发。选区只读取实际选中文字，支持公开选区的只读控件，只提供复制。
- 默认 8 秒隐藏，悬停保持显示并恢复实色；可设置 0 禁用自动隐藏。定位优先避让光标/选区和输入框。
- 保留全部可访问应用模式、排除项、中英日界面、九种翻译方向和五家模型 API。

## 下载与安装

下载 TypeLingo-Windows-x64.zip 并完整解压，运行 TypeLingo.exe 或中文“安装到当前用户.cmd”。更新前先退出托盘旧版。

TypeLingo-Source.zip 是完整源码；SHA256SUMS.txt 用于核对压缩包。设置、紧凑悬浮窗及选区预览 PNG 均来自真实 Windows WPF；测试记录随附件提供。

## 验证范围

Linux 和 Windows 核心测试各 121 项通过；真实 WPF 布局及跨进程 UIA 检查 31 项通过。正式发布流程重复检查后上传附件。第三方应用、真实中日输入法、中文安装脚本及五家付费 API 账户仍需手工验收。
