# v0.4.0-preview.4 — 默认鼠标划词翻译

- 默认模式改为鼠标选中文字后翻译，支持应用阅读区域和网页／文档，不再依赖输入框键盘焦点。
- 按鼠标位置查找 UIA 文本选区；拖选时取消旧请求，松开并稳定后翻译。鼠标移开后继续复核原选区，便于复制和收藏。
- 清除选区不回退到整页或当前行；只读选区不读取全文、不提供替换。
- 常规设置将划词作为首选，输入自动／快捷键模式继续可选。旧输入模式首次升级迁移，之后保留用户保存的选择。
- 增加独立 WPF 阅读文档、真实鼠标拖选及 WebView2 网页正文选区验证，继续覆盖编辑替换与隐私门控。

说明见 [默认划词翻译](SELECTION_TRANSLATION.md)，验证见 [本轮记录](VALIDATION.md)。

# TypeLingo（伴译）v0.3.0

## 本次更新

- 按新的参考图重做白底设置：窄侧栏、分隔行、浅灰输入框、黑色开关，提供浅色/深色/跟随系统三张主题卡片。
- 全部导航及悬浮窗图标改为统一线性矢量资源，替换 EXE、窗口和托盘品牌图标。
- 悬浮窗精简为译文与复制、替换、关闭图标，短译文自动收窄，长译文滚动，背景半透明且文字保持清晰。
- 新增三种出现方式：输入后自动出现、快捷键触发、选中文字后出现。默认快捷键 Ctrl+Alt+T，可在设置修改。
- 快捷键触发前不读取文本；编辑、焦点或配置变化后需要重新触发。选区只读取实际选中文字，支持公开选区的只读控件，只提供复制。
- 默认 8 秒隐藏，悬停保持显示并恢复实色；可设置 0 禁用自动隐藏。定位优先避让光标/选区和输入框。
- 保留全部可访问应用模式、排除项、中英日界面、九种翻译方向和五家模型 API。

## 下载与安装

下载 TypeLingo-Windows-x64.zip 并完整解压，运行 TypeLingo.exe 或中文“安装到当前用户.cmd”。更新前先退出托盘旧版。

TypeLingo-Source.zip 是完整源码；SHA256SUMS.txt 用于核对压缩包。设置、紧凑悬浮窗及选区预览 PNG 均来自真实 Windows WPF；测试记录随附件提供。

## 验证范围

Linux 和 Windows 核心测试各 121 项通过；真实 WPF 布局及跨进程 UIA 检查 31 项通过。正式发布流程重复检查后上传附件。第三方应用、真实中日输入法、中文安装脚本及五家付费 API 账户仍需手工验收。
