# TypeLingo（伴译）v0.1.0

首次发布的 Windows 10/11 x64 实时输入翻译助手。

- 界面语言支持简体中文、英语、日语；安装向导、使用说明和项目注释为中文。
- 提供中译英、英译中、中译日、日译中、英译日、日译英及三种自动识别方向。
- 支持 DeepSeek、OpenAI、Claude、Gemini 和通义千问的 API；可选择或手动输入模型，并打开官方 API 开通平台。
- 自动翻译仅预览。主动请求、确认并再次核实输入框后，才允许替换。
- 包含托盘暂停、输入防抖、缓存、DPAPI 密钥保护及可选的加密磁盘缓存。

## 下载与安装

下载 `TypeLingo-Windows-x64.zip` 并完整解压，直接运行 `TypeLingo.exe`，或运行中文「安装到当前用户.cmd」。安装包包含 .NET 运行时，不需要管理员权限。

`TypeLingo-Source.zip` 为完整源码。`SHA256SUMS.txt` 用于核对两个压缩包是否完整。

## 验证范围

已完成 Linux 上的 Windows 交叉构建，核心自动测试 88 项通过。实际 Windows 桌面、中文安装向导、输入法和五家真实 API 账户调用仍待实机验收。默认模型仅作可编辑起点，以各平台账户的实际可用模型为准。
