# 默认划词翻译

默认使用鼠标拖选文字并松开后翻译。网页正文、只读文档、聊天记录等阅读区域不必是输入框，也不必取得键盘焦点；应用需要通过 Windows UI Automation 的 TextPattern 公开选区。

## 使用

1. 保存自己的 AI 配置，并在「隐私与应用」授权。默认应用范围为所有可访问应用，也可以改为指定进程；排除列表优先。
2. 在外部应用中拖选一段文字并松开。选区稳定达到防抖时间（默认 500 ms）后预览译文；按住鼠标拖选时不翻译中间结果。
3. 移动鼠标到悬浮窗使用复制或收藏，原选区会继续复核。清空选区、切换应用或暂停后隐藏。默认 8 秒自动隐藏，可改为 0 保持显示。
4. 阅读选区只能预览、复制、收藏。可编辑且能核对 ValuePattern 全文与精确范围的目标还支持确认后替换。

在「常规设置」可以切换为「按快捷键出现」或「输入后自动出现」。划词模式中没有选区时，即使按预览快捷键也不会翻译全文或当前行；其他两种模式可读取编辑目标的当前行。

## 升级

首次升级时，旧配置中的输入自动模式切换为划词模式；原有快捷键模式和选区模式保持。保存设置后记录迁移版本，之后手动改回输入自动模式不会再次被迁移。API、隐私授权、应用范围、收藏和缓存保持原配置。

## 边界

程序从鼠标命中的 UIA 元素向上查找选区，找不到时复核已捕获选区或键盘焦点目标。只在当前前台窗口的实际子树中读取，渲染进程也受宿主授权与排除项约束；不遍历整台机器或整页寻找文本。

只读阅读区域只读取所选文字。核对可编辑目标的替换范围时会临时在本机读取全文，但提交翻译的仍是选区或当前行。

图片、扫描 PDF、游戏画面及不公开文本选区的控件无法通过本功能读取；未实现 OCR 或剪贴板取词。不能承诺所有应用均兼容。密码框、敏感控件、排除进程和未授权应用继续跳过。
