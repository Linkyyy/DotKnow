# 划选即问与兼容说明

新安装默认「百科」与「先选择任务或输入问题」。鼠标划选后显示可交互面板，显示本身不调用在线 API；用户查询时才提交所选内容。面板初次出现不激活原应用，点击问题框后接受键盘输入；选区在失焦之前捕获并保留，不会重新读取自己的问题框。

选择「立即执行默认预设」后，翻译沿用紧凑的不激活浮窗；其他任务使用更适合长文的回答面板。「自由提问」仍要求输入问题。自动任务支持先显示 Loading 或仅结果；失败时也会展示原因。手动提问时输入面板保持可见。

关闭或切换外部选区会取消当前请求。提问期间按钮禁用以避免重复发送。旧请求的迟到响应不能显示在新选区，也不能重新打开已关闭的面板。切换到其他应用并清除选区后面板隐藏；仍需围绕原文继续提问时应留在面板中。

百科、解释、摘要、润色、代码解读、自由提问及自定义任务的回答由所选在线模型生成。它们不读取离线词库，不受“仅离线翻译”开关影响，也不自动写入题库。此开关只控制翻译模式；任务页和回答页均明确说明在线范围。

选纯翻译且未添加问题时，保留原缓存键、翻译风格、离线优先、在线回退、自动入库和安全替换。在翻译上添加问题时成为独立 AI 任务，缓存与普通译文分开。

缓存键包含任务 ID、实际指令、回答语言、用户问题、选区及服务商模型等参数。修改自定义提示词或问题不会复用不同任务的回答。收藏保留任务与问题；旧收藏按翻译解释，不需要迁移或解密导出。

新配置增加 Assistant 字段。旧配置缺少此字段时，加载为“翻译＋立即执行”，保留原习惯；新安装为“百科＋任务面板”。数据目录与 DPAPI 用户加密继续兼容 TypeLingo，内部程序集及分发文件使用 DotKnow，面向用户的中文名称为点解。配置损坏时沿用暂停读取和保留原文件策略。

当前没有浏览器工具、实时搜索、对话历史拼接、OCR、代码执行或联网来源核验。提示词不是给模型增加工具；用户自定义任务仍然只使用选区、指令和补充问题。
