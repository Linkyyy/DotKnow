# 离线题库

v0.4.0-preview.5 内置用户提供的 TypeLingo-Vocabulary-zh-en-ja-v1.zip。离线查询不需要模型、网络或 API Key；自动翻译仍须在「隐私与应用」同意读取选区。默认鼠标划词方式保持。

## 开始使用

在「常规设置」选择自然翻译、自动源语言、目标日语，授权后在外部应用选中“米饭”，应显示“ご飯”，来源为“离线题库”。此过程不调用 API。内置数据支持中文、英语、日语六个方向。

在「离线题库」设置页可以：

- 优先使用离线题库：默认开启，先查题库，再查现有缓存，最后在线翻译。关闭后沿用缓存与在线流程。
- 未命中时允许在线翻译：默认开启；关闭后始终只查题库，不调用 API 或使用在线缓存。未命中会提示，无需配置在线密钥。
- 自动积累在线译文：默认开启。在线成功结果、以后实际命中的旧缓存，连同本次原文和翻译条件保存到个人题库。即使内存和磁盘缓存都关闭也生效；可独立关闭。
- 导入 ZIP 或 entries 格式的 UTF-8 JSONL；搜索原文或译文、编辑、删除、导出 ZIP、清空题库、恢复内置词库。列表最多展示 100 条，搜索缩小范围。

缓存只含查询哈希和译文，无法批量还原所有旧缓存的原文；因此不会宣称已迁移从未再次使用的历史缓存。之后实际命中时有原文，才会积累。

## 实际规模与匹配

上传包声明初稿，独立解析与校验得到：6,426 组三语词条、32,159 条可查询方向记录、2,441 组隔离冲突查询。没有把六向展开的记录数冒充一万组词条。来源说明与许可证保留在 docs/vocabulary/，内置数据原包在源码 data/ 中。

按原文、源语言、目标语言、风格、提示词版本精确匹配，保留大小写、标点、空白和换行；不会把单词的译文机械拼成整句。内置数据均为 natural，自定义商务、敬语或直译风格通常会未命中，随后按设置回退在线。

自动源语言不是额外的语言识别模型：查询其他具体源语言方向，只有译文一致且没有已知冲突／删除标记时才命中。多源语言有不同译文时不猜测。在线自动源语言结果无法可靠确定其具体语言，单独保存为 auto 查询，不混入明确语言方向。已有明确方向、歧义或删除标记时不会自动建立遮蔽它们的 auto 条目。

人工修改优先，自动积累不覆盖任何已有条目。导入相同查询的不同答案会隔离该查询，不静默保留最后一个；人工确认编辑后可以重新启用。已删除的查询有持久标记，自动积累不会立即重建；显式导入或恢复内置词库可以恢复相应内容。

## 保存与迁移

公开内置词库以只读资源加载。个人导入、在线积累、人工修改和删除标记独立保存在 `%LOCALAPPDATA%\TypeLingo\vocabulary.db`，正文使用当前 Windows 用户 DPAPI 加密。原文、译文不以明文写入该数据库。题库没有 TTL、不会被缓存清理或缓存容量淘汰。

个人数据在内存中用于查询；数据库损坏或无法解密时保留原文件，不自动联网替代。在线结果本地保存失败时仍可显示译文，并在状态提示保存失败。

导出 ZIP 含明文原文、译文和个人积累，操作前明确确认。跨机器／Windows 用户迁移请导出再导入，不直接复制 DPAPI 数据库。导出附 SHA-256 和内置来源署名。个人新增或在线译文未宣称经过人工审核。

清空题库会删除个人增量并持久停用内置词库，重启不会自动复原；缓存与收藏保留。点击「恢复内置词库」可恢复公开词条，保留仍在的个人修改。上限为 250,000 条查询，达到上限会报错，不自动删除旧内容。

## 导入格式

ZIP 根目录包含 manifest.json、entries.jsonl，可选 ambiguous.jsonl、checksums.sha256、licenses/。formatVersion 支持 1 或 "1.0"。若提供校验文件，校验必须覆盖清单、entries 和存在的 ambiguous 文件，失败则拒绝导入。只读取数据，不执行包内脚本，不向包内路径解压。

```json
{"sourceLanguage":"zh","targetLanguage":"en","sourceText":"面包","translatedText":"bread","style":"natural"}
```

语言代码 zh/en/ja，目标不支持 auto，源 auto 仅用于导出的自动源语言个人查询。风格 natural/literal/business/keigo。JSONL 无效行会统计并跳过，有效部分一次性事务导入；取消或写入失败会回滚，不能导入半份。歧义条目只保留查询键，不自动命中。
