GOOD QUESTIONS

开始之前，
你可能想知道。

下载后怎么开始使用？+

支持 Windows 10 / 11 x64。下载 ZIP 后完整解压，运行 TypeLingo.exe，也可使用包内的当前用户安装脚本。无需额外安装 .NET。首次打开先尝试离线词库；想翻译更多内容，可在设置中选择 AI 服务并填写自己的 API Key。更新前请先退出托盘中的旧版。

没有网络或 API Key，能使用吗？+

可以查询内置离线词库，也可以收藏与复习。离线词库按原文、语言方向、表达风格等精确匹配，内置词条主要为自然风格。未命中的内容需要在线服务；关闭在线回退后，未命中会给出提示。API 服务可能产生费用，由对应服务商收取。

所有软件里划词，都能翻译吗？+

适用于向 Windows UI Automation 提供文本选区的应用。图片、扫描件、部分自绘控件与未开放文本选区的应用暂不支持，不包含 OCR。只读文本可翻译、复制和收藏；替换仅用于能够验证安全写入的可编辑输入框，写入前需要确认。

我的文字和收藏会保存在哪里？+

离线词库命中时不发送 API 请求。在线回退会将待翻译文字发送至你选择的 AI 服务。个人词库、自动积累的在线译文和主动收藏保存在本机，并由当前 Windows 用户加密；你可以关闭在线译文自动入库。导出的词库是明文，请自行妥善保管。

现在有 macOS、手机或正式版吗？+

目前提供 Windows x64 预览版 v0.4.0-preview.5，尚未提供 macOS、Linux 或手机版。你可以在 GitHub 查看开发进展、版本说明和反馈问题。
