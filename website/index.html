GOOD QUESTIONS

开始之前，
你可能想知道。

下载后怎么开始使用？+

支持 Windows 10 / 11 x64。下载 ZIP 后完整解压，运行 DotKnow.exe，也可使用包内的当前用户安装脚本。无需额外安装 .NET。首次打开同意读取选区，在「任务与提示词」选择默认任务和划选方式；在线任务需选择 AI 服务并保存自己的 API Key。只用离线词库时选择翻译预设。更新前先退出旧版托盘。

点知和原来的伴译有什么关系？+

点知由 TypeLingo 伴译升级而来。翻译成为多种任务之一；旧版配置、API 密钥、离线词库和收藏继续使用原有本地目录。升级后保留原来的即时翻译习惯，可在「任务与提示词」切换新模式。

百科是实时联网搜索吗？+

当前通过你选择的在线 AI 模型解释选中内容，不提供实时联网搜索或网页来源核验。遇到时效信息和重要事实，请再核实。网页上的交互为固定示例，不会调用 AI 或读取其他应用。

没有网络或 API Key，能使用吗？+

翻译模式可以查询内置离线词库，也可以查看收藏与复习。百科、解释等任务需要在线模型和你自己的 API Key。离线词库按原文、语言方向、表达风格等精确匹配，内置词条主要为自然风格。未命中的内容需要在线服务；关闭在线回退后，未命中会给出提示。API 服务可能产生费用，由对应服务商收取。

所有软件的内容都能划选查询吗？+

适用于向 Windows UI Automation 提供文本选区的应用。图片、扫描件、部分自绘控件与未开放文本选区的应用暂不支持，不包含 OCR。只读文本可查询、复制和收藏。即时翻译模式下，能够验证安全写入的可编辑输入框支持确认替换；提问面板内的回答以复制为主。

我的文字和收藏会保存在哪里？+

离线词库命中时不发送 API 请求。百科等在线任务或在线翻译会将选区、提示词和补充问题发送至你选择的 AI 服务。个人词库、自动积累的在线译文和主动收藏保存在本机，并由当前 Windows 用户加密；你可以关闭在线译文自动入库。导出的词库是明文，请自行妥善保管。

现在有 macOS、手机或正式版吗？+

目前提供 Windows x64 预览版 v0.5.0-preview.1，尚未提供 macOS、Linux 或手机版。你可以在 GitHub 查看开发进展、版本说明和反馈问题。
