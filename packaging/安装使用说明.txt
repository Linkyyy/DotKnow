TypeLingo（伴译）Windows 中文安装包

适用系统：Windows 10 / 11，64 位。
本包包含 .NET 运行时，无需另外安装 .NET，也无需管理员权限。

一、安装与启动
1. 先完整解压 ZIP，不要直接在压缩包内运行。
2. 直接双击 TypeLingo.exe 即可使用，无需安装。
3. 如果需要桌面和开始菜单快捷方式，双击“安装到当前用户.cmd”。
   安装位置：%LOCALAPPDATA%\Programs\TypeLingo。
   此向导先校验程序 SHA-256，再复制文件；不会设置开机自启。
4. 更新前先从系统托盘退出旧版，再运行新版安装向导。
5. 卸载时先退出程序，再运行“卸载伴译.cmd”。个人设置和加密密钥会保留。

二、界面语言与翻译方向
1. 在“基础”页选择界面语言：简体中文、英语、日语；保存后重启仍保留。
2. “翻译方向”可直接选择中译英、英译中、中译日、日译中、英译日、日译英。
3. 也可选择自动识别输入语言，再翻译成中文、英语或日语。
4. 翻译风格独立设置：自然、直译、商务、敬语。
5. 界面语言只影响按钮、设置和提示，不会改变翻译方向。

三、API 与模型
1. 在“AI”页选择 DeepSeek、OpenAI、Claude、Gemini 或通义千问。
2. 点击“打开官方 API 开通 / 购买平台”，浏览器打开所选服务的官方平台。
3. 在平台开通 API 并获取自己的 API 密钥；网页聊天会员通常不等于 API 额度。
4. 将密钥输入当前服务商的密钥框，点击“查询可用模型”。
5. 从下拉列表选择模型，或手动填写账户有权限使用的文本聊天模型 ID。
6. 若平台不支持模型列表接口，可直接填写模型并使用“测试翻译”。
7. 测试翻译只发送固定短句 Hello，可能产生少量 API 费用。
8. 各服务的默认模型只是初始示例，实际可用性以账户和平台为准。
9. 密钥按“服务商＋API 地址”分别加密保存；留空会保留当前配置已保存的密钥。
   切换服务商或 API 地址不会把上一家的密钥发送到新平台。

四、隐私授权与正常使用
1. 在“隐私”页明确授权，并填写允许的进程名；空列表不会读取任何应用。
2. 例如记事本可尝试 notepad；浏览器可填写 chrome 或 msedge。
   允许浏览器会包含其所有可访问输入框，请谨慎选择。
3. 在允许的输入框中输入，停止输入一小会儿后会在旁边预览译文。
4. 原文始终保持不变；只有主动请求并点击确认替换后才会尝试写入。
5. 替换快捷键：Ctrl+Alt+Enter；暂停全部读取：Ctrl+Alt+Space；复制译文：Ctrl+Alt+C。
6. 无法安全读取、写入或核实输入法状态的控件可能只支持预览、复制，或者直接跳过。
7. 关闭设置窗口后，程序仍在托盘运行；从托盘可暂停或彻底退出。
