点解 DotKnow v0.5.0-preview.3 · Windows 中文安装包
哪里不会，点哪里。

像点读机一样的桌面 AI 助手。划选文字查百科、翻译、解释、摘要、润色、解读代码，或输入自己的问题。

【安装】
适用于 Windows 10 / 11 x64，已包含 .NET 运行时。
1. 完整解压 ZIP，再双击 DotKnow.exe。
2. 也可运行“安装到当前用户.cmd”，先校验程序，再创建点解快捷方式。
3. 更新前先退出旧版点解或伴译的系统托盘。
4. 为兼容旧数据，程序安装目录仍为 %LOCALAPPDATA%\Programs\TypeLingo。
5. “卸载点解.cmd”删除程序及软件快捷方式，保留个人数据。
无需管理员权限，不设置开机自启，不修改系统安全策略。

【首次使用】
1. 在“隐私与应用”同意读取选区，按需设置应用允许与排除列表。
2. 在“AI 服务与模型”选择服务商、保存自己的 API 密钥和可用模型。
3. 新用户默认“百科＋先选择任务或输入问题”。在别的应用划选文字，选择预设，点击查询。
4. 可以在面板补充问题，用 Ctrl+Enter 发送；进入问题框不会丢失刚才的原选区。
5. 在“任务与提示词”新建自己的指令，可设置为默认任务；编辑后点击保存设置。
6. 可选择“立即执行默认预设”，自动查询支持显示 Loading 或完成后再显示。
7. 有用的回答可以复制、收藏，在本地用卡片复习。

【翻译与离线词库】
翻译依然是独立的重要功能。选择内置“翻译”，在常规设置选择语言方向与风格。
纯翻译默认离线词库优先，未命中再按设置在线；可关闭在线回退。
内置 6426 组中英日词条，32159 条可用方向记录，另有歧义隔离。
自然风格、目标日语时，选中“米饭”可离线得到“ご飯”，不需要 API 密钥。
仅离线开关和自动积累只用于纯翻译。百科等任务始终需要在线模型。
翻译任务添加问题后属于 AI 任务，不会将解释积累进词库。
即时翻译的紧凑浮窗中，可点击译文并确认替换可安全写入的选区或当前行。
提问面板的结果通过复制使用，不会直接写回原应用。

【旧版升级】
点解由 TypeLingo 伴译升级而来。旧用户继续默认即时翻译。
配置、API 密钥、词库、收藏和缓存继续位于 %LOCALAPPDATA%\TypeLingo，不需要搬迁。
可以在“任务与提示词”切换为新交互。

【使用范围】
需要应用公开 Windows UI Automation 文本选区；图片、扫描件和部分自绘控件不支持，无 OCR。
百科回答来自模型已有知识，不是实时联网搜索；不核验网页来源，不执行代码，AI 可能有误。
密码与常见敏感控件跳过，软件自身不读取；用户可随时暂停。
在线任务向用户选择的服务商发送选区、指令与问题，可能产生 API 费用。
个人词库和收藏由 Windows 当前用户加密；自定义提示词保存在本机配置文件。

【快捷键与主题】
Ctrl+Alt+T：显示查询面板；Ctrl+Alt+C：复制当前结果。
Ctrl+Alt+Space：暂停全部读取；Ctrl+Alt+Enter：即时翻译准备替换确认。
外观有纯白、浅纸、深林、雾蓝、暮紫，支持浅色、深色和跟随系统。
关闭设置窗口仍在托盘运行，退出请使用托盘“退出”。

真实 Windows 界面与验证记录见 docs/UI_THEMES.md、docs/VALIDATION.md。
中文提示词示例见 docs/PROMPT_PRESETS.md。

中文名“点解”取自粤语“为什么”，鼓励在阅读中随时提出问题。英文名与程序名继续使用 DotKnow，原有数据保持兼容。
